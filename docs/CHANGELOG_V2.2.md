# V2.2 Change Log

- Establishes V2.2 as the active architecture/security baseline, superseding V2.1 on conflicts.
- Adds Security Policy Registry with immutable versions, approval and server-side enforcement.
- Adds Data Lineage with classification/ACL inheritance and deletion propagation.
- Adds Quota & Cost Governance with atomic reservation, usage ledger and reconciliation.
- Adds resilience: deadlines, bounded retry, circuit breaker, bulkheads, DLQ and policy-aware fallback.
- Adds control-plane SQL and gRPC contracts, ADR-011…ADR-014, implementation backlog and SEC-016…SEC-025.
- Adds mandatory AI agent entrypoint and governance files at repository root.
